# PrintWise

Don't you just hate when your 3D print is more brittle than glass? PrintWise can fix that! With a simple survey for your 3D model, it recommends the right print settings for your slicer!

This is a passion project being developed by a sophomore! 
## Goals

Analyze 3D models
Recommend print settings
Explain engineering reasoning behind recommendations
